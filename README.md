# alpr-per-department

Ties crowdsourced OpenStreetMap camera data (the DeFlock layer) to US local police agencies, checks the mapped
counts against publicly reported ones, and compares observation counts in ALPR court rulings with *Carpenter*.
Method write-up: `docs/METHODS.md`.

## Charts

| Chart | Made by | From |
|---|---|---|
| `output/validation_web_scatter.png`: reported vs. mapped cameras, 360 agencies | `R/09_validate_web.R` | pipeline + `data/validation_web/` |
| `output/hist_web_sample_reported_vs_osm.png`: the same agencies, distribution of each count | `R/11_hist_web_sample.R` | `output/validation_web_comparison.csv` |
| `output/court_observations_per_day.png`: captures per day in court rulings vs. *Carpenter* | `R/court_observation_chart.R` | `docs/alpr_observation_counts.xlsx` |

`output/validation_web_comparison.csv` (one row per agency) and `output/validation_web_metrics.csv` are the data behind
the two validation charts. Other outputs are regenerated by a run and not kept in git.

## Layout

| Path | Contents |
|---|---|
| `R/01`–`07` | pipeline: Census boundaries, OSM cameras, agency list, operator-tag match (method A), operator classes, spatial assignment (method B), combined camera and agency tables |
| `R/09`, `R/11` | validation against reported counts and the two validation charts |
| `R/court_observation_chart.R` | court chart |
| `R/run_all.R` | runs everything in order |
| `R/name_parser.R`, `R/theme_cf.R`, `R/operator_class_overrides.csv` | shared helpers, chart style, reviewed operator classes |
| `data/snapshots/` | OSM snapshot of 2026-10-03 and its Overpass query log |
| `data/validation_web/` | publicly reported camera counts (URL and quote per row), status overrides, Minnesota BCA register |
| `data/raw/leaic/` | LEAIC 2012 (ICPSR 35158) |
| `docs/alpr_observation_counts.xlsx` | observation counts in ALPR Fourth Amendment rulings, with sources |

## Rerunning

```
export LC_ALL=C.UTF-8     # some regexes use non-ASCII characters
Rscript R/run_all.R       # --pull for a new OSM snapshot (~2 h, R/02_pull_osm.R); --from 03 to skip downloads
```

- **R packages:** sf, dplyr, readr, tidyr, stringr, purrr, jsonlite, httr2, stringdist, ggplot2, scales, ragg, readxl.
- **Font:** Liberation Sans. If it isn't installed, `R/theme_cf.R` loads a copy from `data/raw/fonts/`.
- **Downloaded during a run, not kept in git:**
  - Census TIGER 2025 and ACS 2020-24 (`01_download_census.R`);
  - the FBI Crime Data Explorer agency directory and employee file (`03_agencies.R`).
- **Logs:** go to `output/log_<script>.txt`.

## Known limits

- 84% of OSM cameras have no operator tag. Untagged cameras of other operators inside an agency's area count for that agency.
- Volunteer mapping coverage is uneven, and car-mounted readers are not in OSM.
- LEAIC is old, so newer agencies are matched by name. ICPSR's terms bar redistributing the LEAIC file: remove it from history before making the repo public.
- Agencies with a published count are not a random sample.
